# Stories

This directory is a small, tool-neutral record of planned and completed work. Keep one Markdown
file per story and register it in [`INDEX.md`](./INDEX.md), newest first.

Each story has a numeric ID, a Conventional Commit type, a short intent, checkable acceptance
criteria, and validation notes. Use `OPEN`, `IN_PROGRESS`, or `CLOSED`. Historical stories can be
reconstructed from commits and should include the relevant commit IDs in the story.

The repository workflows live in `.agents/skills/` and are plain `SKILL.md` files, independent of a
specific editor, CLI, or AI vendor.
